# AI Engineering

Final projects from my AI Engineering learning journey, focused on building practical applications with Python, large language models (LLMs), AI agents, and modern AI frameworks.

## Topics

- AI foundations and tools
- Building AI applications with Python
- LangChain
- LangGraph and MCP
- AI agents and workflow patterns, including ReAct and Human-in-the-Loop
- Advanced LangGraph applications
- Retrieval- and knowledge-augmented systems: RAG, CAG, and KAG
- Vector databases and knowledge graphs
- Local model execution with Ollama
- Hugging Face models and tooling
- LLM and multimodal model fine-tuning with tools such as Unsloth

## Goals

- Apply concepts from the course through end-of-chapter projects.
- Build a clear portfolio of practical AI engineering work.
- Document each project with setup instructions, usage examples, and key implementation details.

## Project Standards

Each project should include, where applicable:

- A project-specific `README.md`
- Clear setup and execution instructions
- A dependency list
- Example configuration such as `.env.example` when needed
- Tests or sample usage
- No committed API keys, passwords, private data, or large model files
